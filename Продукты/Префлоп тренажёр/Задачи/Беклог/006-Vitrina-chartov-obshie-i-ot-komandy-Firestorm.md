# **006. Витрина чартов: общие и от команды Firestorm**

## **Input**
- Нужно разделить чарты на два слоя: общие и собранные командой Firestorm.
- Пользователь должен понимать разницу и ценность каждого слоя.

## **Output**
- Раздел `Общие чарты` добавлен.
- Раздел `Чарты команды Firestorm` добавлен.
- Подписи о различии разделов написаны.
- Переходы из витрины в тренировку и просмотр чарта настроены.

## **Outcome**
- Пользователь быстрее находит подходящий материал.
- Повышается ценность экспертных паков команды.

## **Действия по задаче (в совершённом виде)**
- Структура витрины из двух разделов собрана.
- Карточки чартов для двух разделов добавлены.
- Поясняющий текст про отличие разделов написан.
- Переходы `Посмотреть` и `Тренироваться` добавлены.

## **Чек-лист проверки**
- [ ] На экране явно видны два раздела: общие и Firestorm.
- [ ] Пользователь понимает разницу без дополнительных пояснений менеджера.
- [ ] Из каждого раздела работает переход в тренировку.
- [ ] Скриншот экрана витрины во всю ширину сделан.
