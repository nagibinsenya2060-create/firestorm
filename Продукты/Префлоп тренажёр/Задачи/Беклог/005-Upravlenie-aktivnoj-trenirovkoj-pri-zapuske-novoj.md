# **005 Управление активной тренировкой при запуске новой**

## **Problem Statement**

- Ожидалось: пользователь может запустить новую тренировку без путаницы, когда текущая сессия уже активна.
- Фактически: показывается неочевидное модальное окно с `Нет/Да`, где неясно последствие выбора.
- Граница: сценарий запуска новой тренировки при наличии незавершённой текущей.

## **Input**

- Есть пользовательский сценарий, где новая тренировка запускается поверх активной.
- Есть текущий модал с формулировкой про принудительное завершение.
- Итоговая реализация пока не зафиксирована и должна быть выбрана на этапе проектирования решения.

## **Output**

- Целевой пользовательский флоу при конфликте `активная тренировка vs новая тренировка` зафиксирован.
- Однозначные действия в интерфейсе вместо `Нет/Да` написаны.
- Действие `Продолжить текущую тренировку` реализовано или явно предусмотрено в финальном решении.
- Действие `Завершить текущую и начать новую` реализовано.
- Состояние текущей сессии при выборе каждого действия корректно обработано.
- Ошибочный запуск новой тренировки без явного подтверждения завершения старой исключён.

## **Outcome**

- Пользователь быстрее понимает, что произойдёт при запуске новой тренировки.
- Снижается риск случайного завершения текущей сессии.
- Флоу запуска новой тренировки становится предсказуемым и управляемым.

## **Декомпозиция**

### **Этап 1. Проектирование решения**

- Финальный сценарий поведения при активной сессии зафиксирован.
- Вариант интерфейса (модал, статичный блок или комбинированный вариант) выбран.
- Тексты действий и сообщений согласованы.

### **Этап 2. Реализация**

- Логика выбора действия пользователя реализована.
- Обработка завершения старой и запуска новой тренировки реализована.
- Обработка возврата в текущую тренировку реализована.

### **Этап 3. Проверка**

- Сценарий `активная сессия -> выбрал продолжить текущую` проверен.
- Сценарий `активная сессия -> выбрал завершить и начать новую` проверен.
- Сценарий закрытия модала/экрана без действия проверен.

## **Чеклист проверки**

- [ ] Целевой флоу зафиксирован.
- [ ] Однозначные тексты действий написаны.
- [ ] Действие `Продолжить текущую тренировку` реализовано или зафиксировано в утверждённом решении.
- [ ] Действие `Завершить текущую и начать новую` реализовано.
- [ ] Переходы состояний сессии обработаны корректно.
- [ ] Ошибочный запуск новой тренировки без подтверждения исключён.
- [ ] Основные пользовательские сценарии проверены.

## **Визуальное подтверждение**

- Скриншот 1 (полная ширина): экран/модал выбора действия при активной тренировке.
- Скриншот 2 (полная ширина): переход по сценарию `Продолжить текущую`.
- Скриншот 3 (полная ширина): переход по сценарию `Завершить и начать новую`.
