# **002 Страница о тренажёре и вход в тренажёрный флоу**

## **Problem Statement**

- Ожидалось: пользователь может зайти в тренажёр через понятный рыночный входной флоу.
- Фактически: нет отдельной страницы о тренажёре и цельного сценария `узнал -> зарегистрировался -> попал в тренажёр`.
- Граница: путь от страницы о тренажёре до первого входа в тренировку.

## **Input**

- Тренажёр существует как инструмент внутри экосистемы сайта.
- Отдельная лендинговая страница тренажёра как точка входа отсутствует.
- Для релиза нужен прямой пользовательский вход через `Telegram`, `Email`, `Google`.

## **Output**

- Отдельная страница о префлоп-тренажёре добавлена.
- Ценностное описание тренажёра для нового пользователя написано.
- Блок CTA `Начать тренировку` добавлен.
- Вариант регистрации/входа через `Telegram` добавлен.
- Вариант регистрации/входа через `Email` добавлен.
- Вариант регистрации/входа через `Google` добавлен.
- Единый маршрут перехода со страницы о тренажёре в тренажёр после успешной регистрации/входа реализован.
- Сценарий первого входа пользователя без существующей сессии проверен.
- Сценарий повторного входа пользователя с существующей сессией проверен.

## **Outcome**

- Пользователь попадает в тренажёр через понятный и управляемый флоу.
- Снижается отвал на этапе первого входа.
- Появляется базовая точка для маркетингового трафика и конверсии в регистрацию.

## **Декомпозиция**

### **Этап 1. Страница о тренажёре**

- Структура страницы о тренажёре собрана.
- Ценностные блоки и ключевые преимущества описаны.
- CTA на вход в тренажёр выведен.

### **Этап 2. Авторизация**

- Вход через `Telegram` подключён.
- Вход через `Email` подключён.
- Вход через `Google` подключён.

### **Этап 3. Сквозной флоу**

- Переход в тренажёр после успешного входа реализован.
- Ошибки авторизации с понятным сообщением обработаны.
- Возврат пользователя в корректное состояние после отмены входа реализован.

### **Этап 4. Проверка пути**

- Сценарий `новый пользователь -> регистрация -> тренажёр` проверен.
- Сценарий `возвратный пользователь -> вход -> тренажёр` проверен.
