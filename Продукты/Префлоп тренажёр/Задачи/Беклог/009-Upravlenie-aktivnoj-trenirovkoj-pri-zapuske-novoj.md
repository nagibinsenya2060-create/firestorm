# **009. Управление активной тренировкой при запуске новой**

## **Input**
- При попытке начать новую тренировку поверх активной показывается неочевидный попап.

## **Output**
- Тексты в модальном окне переписаны в явные действия.
- Пользователь видит понятный выбор: продолжить текущую или завершить и стартовать новую.
- Результат каждого выбора обработан без потери данных.

## **Outcome**
- Устранена путаница при конфликте двух сессий.
- Уменьшено число случайных завершений.

## **Действия по задаче (в совершённом виде)**
- Тексты действий в модальном окне написаны.
- Сценарий `Продолжить текущую` реализован.
- Сценарий `Завершить текущую и начать новую` реализован.
- Обработка закрытия модального окна без действия реализована.

## **Чек-лист проверки**
- [ ] Пользователь понимает последствия каждого действия до клика.
- [ ] Обе ветки сценария отрабатывают корректно.
- [ ] Прогресс текущей сессии не ломается.
- [ ] Скриншоты двух веток сценария во всю ширину экрана сделаны.
