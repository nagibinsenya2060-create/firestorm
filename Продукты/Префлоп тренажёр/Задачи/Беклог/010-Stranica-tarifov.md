# **010. Страница тарифов**

## **Input**
- Для коммерческого запуска нужна прозрачная тарификация.

## **Output**
- Страница тарифов создана.
- Состав каждого тарифа зафиксирован.
- Отличия между тарифами показаны в сравнении.
- CTA `Выбрать тариф` добавлен.

## **Outcome**
- Пользователь быстрее принимает решение о покупке.
- Команда получает основу для монетизации.

## **Действия по задаче (в совершённом виде)**
- Набор тарифов согласован и описан.
- Карточки тарифов собраны.
- Сравнительная таблица функционала добавлена.
- Кнопки выбора тарифа добавлены.

## **Чек-лист проверки**
- [ ] Тарифы и цены отображаются без противоречий.
- [ ] Отличия между тарифами читаются быстро.
- [ ] Кнопка выбора тарифа ведёт к оплате.
- [ ] Скриншот страницы тарифов во всю ширину экрана сделан.
