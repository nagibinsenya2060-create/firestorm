# **006 Разбор ошибки в момент ответа (аналог Duolingo)**

## **Problem Statement**

- Ожидалось: пользователь после ошибки сразу понимает, что сделал не так и как исправиться.
- Фактически: путь до понимания ошибки длинный, разбор разнесён по шагам, усталость накапливается.
- Граница: момент после неверного ответа в тренировочной сессии.

## **Input**

- Есть сценарий тренировки с правильными/неправильными ответами.
- В текущем флоу нет достаточного мгновенного визуального разбора ошибки.
- Нужно сократить путь обучения по принципу короткого цикла обратной связи (аналог Duolingo).

## **Output**

- Мгновенный экран/блок разбора после неверного ответа добавлен.
- Чарт/диапазон правильного решения сразу после ошибки выведен.
- Зона ошибки пользователя на чарте подсвечена.
- Короткий объясняющий текст по ошибке выведен.
- Кнопка быстрого перехода к следующей попытке/следующей ситуации добавлена.
- Длительный обходной путь к разбору ошибки исключён.

## **Outcome**

- Пользователь быстрее понимает ошибку и закрепляет корректное решение.
- Когнитивная нагрузка и усталость в тренировке снижаются.
- Качество отработки ошибок и вовлечённость в сессию растут.

## **Декомпозиция**

### **Этап 1. Микрофлоу фидбека**

- Сценарий показа разбора сразу после неверного ответа зафиксирован.
- Структура блока `ошибка -> правильный чарт -> пояснение -> следующее действие` зафиксирована.
- Тексты короткого фидбека согласованы.

### **Этап 2. Визуализация ошибки**

- Правильный чарт по ситуации после ошибки выведен.
- Ошибочное действие пользователя на чарте подсвечено.
- Различимость правильной зоны и ошибочной зоны проверена.

### **Этап 3. Проверка скорости цикла**

- Сценарий `ошибка -> понял -> продолжил` проверен на одном экране/коротком пути.
- Избыточные переходы и дополнительные экраны убраны.
- Повторная ошибка в следующей ситуации корректно обрабатывается.

## **Чеклист проверки**

- [ ] Мгновенный блок разбора ошибки добавлен.
- [ ] Правильный чарт после ошибки выведен.
- [ ] Зона ошибки пользователя подсвечена.
- [ ] Короткий обучающий текст выведен.
- [ ] Кнопка быстрого перехода к следующему действию добавлена.
- [ ] Длинный обходной путь к разбору исключён.
- [ ] Сценарий `ошибка -> разбор -> продолжение` проверен.

## **Визуальное подтверждение**

- Скриншот 1 (полная ширина): момент неверного ответа.
- Скриншот 2 (полная ширина): экран/блок мгновенного разбора с чартом и подсветкой ошибки.
- Скриншот 3 (полная ширина): переход к следующей попытке/ситуации после разбора.
