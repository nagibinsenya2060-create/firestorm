# **011. Интеграция оплаты и выбор эквайринга**

## **Input**
- После выбора тарифа пользователь должен оплатить и сразу получить доступ.

## **Output**
- Эквайринг для релиза выбран.
- Платёжный сценарий `выбрал тариф -> оплатил -> получил доступ` реализован.
- Ошибка оплаты обработана корректно.
- Статусы платежей фиксируются.

## **Outcome**
- Монетизация работает сквозным продуктовым путём.
- Снижается ручная поддержка по доступам после оплаты.

## **Действия по задаче (в совершённом виде)**
- Критерии выбора эквайринга зафиксированы.
- Интеграция платежа подключена.
- Успешный платёж с активацией доступа реализован.
- Неуспешный платёж с сохранением корректного статуса реализован.

## **Чек-лист проверки**
- [ ] Выбран и зафиксирован релизный эквайринг.
- [ ] Оплата успешного кейса активирует доступ.
- [ ] Неуспешный платёж не активирует доступ.
- [ ] Скриншоты успешного и неуспешного сценариев сделаны во всю ширину экрана.
