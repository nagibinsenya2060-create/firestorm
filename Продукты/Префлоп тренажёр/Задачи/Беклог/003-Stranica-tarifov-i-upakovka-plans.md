# **003 Страница тарифов и упаковка планов**

## **Problem Statement**

- Ожидалось: пользователь может быстро сравнить планы и выбрать тариф перед оплатой.
- Фактически: нет отдельной страницы с зафиксированной тарификацией и единым правилом выбора плана.
- Граница: путь от интереса к продукту до выбора конкретного тарифа.

## **Input**

- Есть запрос на обязательную страницу тарификации перед релизом.
- Нужно продумать состав тарифов для тренажёра.
- Тарифы должны быть подготовлены к следующему шагу: подключение оплаты.

## **Output**

- Отдельная страница тарифов добавлена.
- Тариф `Free/Trial` (если используется) описан.
- Базовый платный тариф описан.
- Расширенный тариф описан.
- Для каждого тарифа функциональные лимиты зафиксированы.
- Для каждого тарифа цена и период оплаты зафиксированы.
- Отличия между тарифами в сравнительном блоке показаны.
- CTA `Выбрать тариф` для каждого плана добавлен.
- Правило выбора тарифа перед оплатой описано и согласовано.

## **Outcome**

- Пользователь быстрее принимает решение о покупке.
- Команда получает стабильную основу для paywall и оплаты.
- Снижается неопределённость по монетизации на этапе релиза.

## **Декомпозиция**

### **Этап 1. Конфигурация тарифов**

- Сетка тарифов и названия планов определены.
- Лимиты и доступный функционал по каждому плану зафиксированы.
- Цена и период оплаты по каждому плану зафиксированы.

### **Этап 2. Страница тарификации**

- Страница тарифов собрана.
- Карточки тарифов с описанием ценности выведены.
- Сравнение тарифов по ключевым функциям выведено.

### **Этап 3. Переход к оплате**

- Кнопки `Выбрать тариф` добавлены.
- Сценарий выбора тарифа перед оплатой реализован.
- Сценарий возврата и смены выбранного тарифа реализован.
