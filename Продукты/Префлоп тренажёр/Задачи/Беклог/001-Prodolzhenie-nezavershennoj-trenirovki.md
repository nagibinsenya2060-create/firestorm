# **001 Продолжение незавершённой тренировки**

## **Problem Statement**

- Ожидалось: пользователь всегда возвращается в незавершённую тренировку.
- Фактически: после закрытия попапа путь продолжения теряется.
- Граница: страница выбора дисциплин/паков в тренажёре.

## **Input**

- Есть экран выбора дисциплин/паков.
- Есть попап `Незавершённая тренировка` с кнопками `Продолжить` и `Завершить`.
- Статичный блок продолжения на странице отсутствует.

## **Output**

- Статичный блок `Незавершённая тренировка` на странице выбора дисциплин/паков добавлен.
- Текст кнопки `Продолжить` написан.
- Текст кнопки `Завершить и начать новую` написан.
- Название пака/дисциплины в блоке выведено.
- Краткий прогресс (`ситуаций`, `верно`, `ошибок`) в блоке выведен.
- Переход по кнопке `Продолжить` в ту же сессию реализован.
- Завершение старой сессии по кнопке `Завершить и начать новую` реализовано.
- Путь продолжения после закрытия попапа сохранён.
- Путь продолжения после refresh страницы сохранён.
- Путь продолжения после повторного входа в аккаунт сохранён.
- Попап в информирующий режим переведён или удалён как обязательная точка входа.

## **Outcome**

- Путь возврата в тренировку не теряется.
- Прогресс пользователя сохраняется.
- Отвал из-за потери сессии снижается.

## **Декомпозиция**

### **Этап 1. UI блока продолжения**

- Заголовок блока `Незавершённая тренировка` добавлен.
- Кнопка `Продолжить` добавлена.
- Кнопка `Завершить и начать новую` добавлена.
- Название пака/дисциплины выведено.
- Блок прогресса выведен.

### **Этап 2. Логика сессии**

- Статус незавершённой сессии сохранён.
- Возврат в ту же сессию реализован.
- Завершение старой сессии реализовано.
- Очистка блока после завершения реализована.

### **Этап 3. Поведение попапа**

- Попап в режим уведомления переведён или удалён.
- Сценарий после закрытия попапа без потери пути проверен.

### **Этап 4. Проверка пользовательского пути**

- Сценарий `начал -> вышел -> вернулся -> продолжил` проверен.
- Сценарий `начал -> вышел -> завершил -> начал новую` проверен.
- Сценарий `закрыл попап -> продолжил из статичного блока` проверен.
