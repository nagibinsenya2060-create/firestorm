## Problem Statement

- Ожидалось: иметь быстрый артефакт для ответа на вопрос “у какого конкурента какой функционал за какую стоимость”.
- Фактически: данные были распределены по отдельным файлам конкурентов, но единой матрицы ещё не было.
- Граница задачи: матрица агрегирует уже подтверждённые публичные данные и не заменяет детальные документы по каждому конкуренту.

Уверенность: 80% -> 97% — цель файла понятна и напрямую поддерживает будущие сравнения по конкурентам.

## Input

- Уже собраны документы по `FreeBetRange`, `ICMIZER 3`, `PreflopHero MTT`, `PokerIQ`, `ЁпрстПокер`
- Для `FreeBetRange` дополнительно есть детализация по странице plan и скриншоту пользователя
- По части конкурентов цены могут быть в разных валютах и форматах отображения

## Output

- Создан единый файл-матрица.
- Для каждого конкурента зафиксированы стоимость, тип тарифа, core-функционал и ключевые differentiators.
- Матрица пригодна для быстрых сравнений в последующих обсуждениях.

## Outcome

- Можно быстро отвечать на вопросы о сравнении конкурентов.
- Снижается риск путать “тренажёр”, “платформу” и “аналитический калькулятор”.
- Дальше проще собирать продуктовые выводы и обсуждать цену `Firestorm`.
