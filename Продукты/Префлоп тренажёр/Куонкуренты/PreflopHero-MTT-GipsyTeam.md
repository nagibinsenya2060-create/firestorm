## Функционал

### Подтверждённые возможности

По публичной карточке продукта и странице подписки подтверждаются такие функции:
- Тренировка префлоп-ситуаций в симуляторе, приближенном к реальной сессии
- Выбор сайзингов и действий как в игровой среде
- Сравнение ответов пользователя с заданными чартами
- Подсветка неоптимальной игры
- Создание своих чартов
- Просмотр доступных чартов
- Просмотр статистики по сыгранным ситуациям
- Просмотр истории ошибок
- Использование на разных устройствах
- Возможность самим создавать ситуации для тренажёра
- Работа с чартами, где сайзинги задаются в `BB`

### Trial-версия

- Тренировка `EP` для доступных паков чартов (`OR`, `vs 3bet`)
- Просмотр доступных чартов
- Просмотр статистики по сыгранным ситуациям
- Просмотр истории ошибок

### Premium-версия

- Тренировка всех префлоп-ситуаций
- Просмотр доступных чартов
- Создание своих чартов
- Просмотр статистики
- Просмотр истории ошибок

### Дополнительно заявлено для GTO-пака

- Чарты для `12`, `15`, `21`, `25 BB`
- Позиции: `EP`, `MP1`, `MP2`, `HJ`, `CO`, `BTN`, `SB`, `BB`
- Сценарии: `or`, `vs or`, `vs 3bet`

#### Что особенно важно

- Это очень близкий конкурент именно в категории “прикладной префлоп-тренажёр”.
- В отличие от `FreeBetRange` и `ICMIZER`, продукт не перегружен образом “большой платформы” или “математического калькулятора”.
- Его ценность лежит в привычке, повторении и тренировке ошибок в почти игровом интерфейсе.

#### Инсайт для Firestorm

- Это один из наиболее релевантных конкурентов для нашего продукта по типу восприятия.
- Если пользователь хочет именно “натренировать префлоп до автоматизма”, сравнение с `PreflopHero MTT` будет для нас прямым.

## Доступность и UX-доступ

### Техническая доступность

- Продукт доступен на разных устройствах.
- Судя по официальной витрине и подписке, это веб-доступ с логином в продукт.
- Пользователь может покупать подписку напрямую внутри приложения.

### Продуктовая доступность

- Есть бесплатная `Trial`-версия.
- Есть платный `Premium`.
- Ценность продукта объясняется быстро: тренируешь, ошибаешься безопасно, видишь ошибки, повторяешь.

### Ограничения

- В GipsyTeam товар сейчас отмечен как `Нет в наличии`.
- Для регистрации требуется только `Gmail`.
- Альтернативные способы оплаты не встроены прямо как self-service, а предлагаются через контакт с поддержкой.

#### Инсайт для Firestorm

- Ограничение на `Gmail` — явная точка трения, которой у нас лучше не допускать.
- Если у нас вход и регистрация будут проще, это может быть конкретным конкурентным преимуществом.
- Простая и самодостаточная регистрация без ручного контакта с поддержкой будет восприниматься как более современный продуктовый опыт.

## Сильные стороны конкурента

- Очень понятное позиционирование
- Узкий и ясный JTBD: тренировать префлоп в MTT
- Есть бесплатный вход через `Trial`
- Есть пользовательские чарты
- Есть история ошибок и статистика
- Есть возможность вручную создавать ситуации
- Доступная цена
- Ориентация на реальную игровую механику

## Слабые стороны конкурента

- Ограничение регистрации только на `Gmail`
- На GipsyTeam товар сейчас `Нет в наличии`
- Более узкий функциональный периметр по сравнению с платформами вроде `FreeBetRange`
- Публично не видно сильного командного или B2B-сценария
- Менее сильное аналитическое ядро, чем у `ICMIZER`

## Что можно взять себе

- Простое и понятное продуктовое обещание
- Фокус на “реально похожую тренировку”, а не на абстрактное изучение
- Отображение ошибок и статистики как центральный сценарий
- Trial, который даёт попробовать продукт без большой цены входа
- Возможность пользователю создавать собственные тренировочные споты

## Что не стоит повторять бездумно

- Не стоит вводить искусственное ограничение вроде `Gmail only`.
- Не стоит допускать ситуацию, когда витрина продаж показывает `Нет в наличии`, если продукт в целом должен восприниматься как живой SaaS.
- Не стоит делать оплату через ручной контакт с поддержкой для альтернативных методов, если можно встроить это чище.

- По типу продукта `PreflopHero MTT` ближе к нам, чем `ICMIZER 3`.
- Это значит, что сравнительный анализ UX, онбординга и value proposition здесь важнее, чем сравнение глубины математики.
