## Функционал

### Ядро продукта

По публичным страницам у FreeBetRange подтверждаются четыре основных модуля:
- `Editor`
- `Trainer`
- `Viewer`
- `Library`

### Подтверждённые функции

- Создание собственных префлоп-диапазонов
- Хранение диапазонов внутри аккаунта
- Импорт диапазонов из внешних программ
- Экспорт диапазонов
- Просмотр стратегии в формате динамических префлоп-чартов
- Тренировка диапазонов
- Два режима тренировки:
- `Classic` — решения как за реальным столом
- `Range-drawing` — восстановление диапазона по памяти
- Доступ к GTO-библиотеке
- Поддержка форматов `Cash`, `MTT`, `Spin&Go`
- Поддержка `6+ Hold'em`
- Быстрый шаринг диапазонов по ссылке
- Загрузка hand history в `Elite`
- Массовый импорт из `HRC` в `Elite`
- Командный тариф с командным дашбордом и отслеживанием прогресса обучения

### Что особенно важно

- Это не узкий тренажёр, а платформа для полного цикла работы с префлоп-стратегией.
- Ценность строится не только на “потренироваться”, но и на “собрать свою систему обучения”.
- У продукта сильный сетевой эффект для тренеров, школ и команд за счёт импорта, экспорта, библиотек и team-функций.

#### Инсайт для Firestorm

- Если наш продукт будет только тренажёром без viewer/editor/library, пользователь может воспринимать его как более узкий и менее ценный.
- Даже если мы не делаем всю платформу сразу, в позиционировании нужно явно объяснить, почему узкий фокус выгоднее.

## Доступность и UX-доступ

### Техническая доступность

- Продукт работает прямо в браузере.
- Установка не требуется.
- Доступ возможен с разных устройств.
- На сайте указано, что данные и прогресс синхронизируются между устройствами.
- Вход возможен после создания аккаунта, в том числе через Google.

### Продуктовая доступность

- Есть бесплатный тариф для входа без покупки.
- Есть онбординг с выбором основного формата игры (`Cash`, `MTT`, `Spins`).
- Бесплатный план ограничивает тренировку до `50` рук / `5` диапазонов в день.
- Бесплатный план даёт только базовый уровень диапазонов, viewer, editor, import/export.

### Ограничения

- Для части румов использование во время игры запрещено. На витрине GipsyTeam явно упомянуты `ПокерОК`, `PokerStars`, `PartyPoker`.
- Для покупки через GipsyTeam нужна отдельная регистрация на сайте продукта.

#### Инсайт для Firestorm

- Браузерный формат резко снижает барьер входа.
- Ограниченный free-tier даёт пользователю быстрый пробный опыт, но сохраняет мотивацию платить.
- Важно заранее продумать нашу политику безопасного использования, чтобы у пользователя не возникало сомнений, можно ли применять продукт рядом с реальной игрой.

- Связка “конструктор + библиотека + viewer + trainer + импорт + hand history” может быть сильной для профи, но менее ясной для пользователя, которому нужна только одна конкретная задача.
- Наличие ограничений по использованию рядом с покер-румами создаёт дополнительную тревогу и требует явной коммуникации.

- Браузерный доступ как базовый стандарт

- Не стоит копировать широкий функциональный периметр, если мы не можем обеспечить качество по всем модулям.
- Не стоит делать запутанный путь покупки с несколькими отдельными сущностями, если можно держать оплату и активацию проще.
- Не стоит перегружать маркетинговое сообщение перечислением всех функций вместо одного сильного обещания.

- `Free` для входа
- `Pro` для регулярной самостоятельной работы
