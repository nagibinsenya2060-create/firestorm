## Краткая выжимка

- `GTO Wizard` — браузерная GTO-платформа для большинства покерных дисциплин.
- Продукт сочетает три крупных слоя:
- просмотр решений
- практику в игровых ситуациях
- анализ истории раздач
- У продукта огромная библиотека предрешённых сценариев: `10,000,000+`
- Есть бесплатная лицензия с доступом ко всем префлоп-решениям и ограниченным постфлоп/практика-доступом.
- Это очень сильный конкурент платформенного и образовательного класса.

## Стоимость

### Что подтверждено по GipsyTeam

На витрине GipsyTeam:
- есть бесплатная лицензия `GTO Wizard` — `$0`
- платные планы стартуют `от $39/мес`

### Структура планов

По карточке GipsyTeam есть планы по дисциплинам:
- `Cash Game Starter / Premium / Elite / Ultra`
- `MTT Starter / Premium / Elite / Ultra`
- `HU SNG Starter / Premium / Elite`
- `HU SNG + Spin & Go Starter / Premium / Elite / Ultra`
- `Straddle + Ante Premium / Elite / Ultra`

### Что важно

- Публичная карточка хорошо раскрывает функционал каждого плана, но не даёт один компактный универсальный прайс-лист по всем вариантам.
- Поэтому в базе лучше хранить не только цену, но и саму логику: `Starter -> Premium -> Elite -> Ultra`.

#### Инсайт для Firestorm

- Это конкурент из другого ценового и продуктового класса.
- Если пользователь ищет “максимально полный GTO-комбайн”, он будет сравнивать нас именно с такими решениями.

## Функционал

### Подтверждённые ключевые возможности

- Браузер решений
- GTO-практика в игровых ситуациях
- Анализ истории раздач
- Префлоп и постфлоп решения
- Фильтры и кастомизация отображения
- Таблица диапазонов, стол и график, матрица рук
- Статистика и история в режиме практики
- Выявление GTO-ошибок по hand history
- Поддержка мобильных устройств

### Поддерживаемые дисциплины

- `Cash holdem`
- `MTT`
- `Spin & Go`
- `HU SNG`
- `6-max / 8-max Straddle + Ante`

### Что получает пользователь даже бесплатно

- доступ ко всем префлоп-решениям
- доступ к одному постфлоп-решению
- по `10` рук в каждом режиме практики в день

### Отличия по уровням

#### Starter

- все префлоп-решения
- ограниченные постфлоп-решения по конкретным стековым глубинам
- неограниченные споты в практике в рамках стартового покрытия
- анализ `50` раздач в месяц
- базовые отчёты

#### Premium

- все функции `Starter`
- расширенное постфлоп-покрытие
- оценка блокеров
- анализ `100,000` раздач в месяц
- доступ к полным отчётам
- еженедельные групповые занятия с тренером в Zoom

#### Elite

- все функции `Premium`
- пользовательские решения с `AI`
- `Nodelocking` или аналогичные продвинутые режимы в отдельных дисциплинах
- анализ `150,000` раздач в месяц
- продвинутые отчёты
- расширенные AI-сценарии

#### Ultra

- все функции `Elite`
- мультипот-префлоп расчёты до `9` человек
- `Power Credits` для агрегированных отчётов
- дополнительные расширения по пользовательским настройкам, ICM и Bounty в зависимости от дисциплины

#### Что особенно важно

- Это один из самых “полных” конкурентов в выборке.
- По сравнению с `Firestorm` он продаёт не просто тренажёр, а универсальную систему изучения и анализа GTO.

#### Инсайт для Firestorm

- В лоб конкурировать с таким продуктом по ширине почти бессмысленно.
- Нужно выигрывать через фокус, простоту, скорость первого value и, возможно, через лучшую подачу именно префлоп-обучения.

## Доступность и UX-доступ

### Техническая доступность

- Браузер
- Desktop и mobile
- Не требует мощного компьютера

### Продуктовая доступность

- Есть `Free`-вход
- Можно начать с префлоп-решений бесплатно
- Есть постепенная лестница апгрейда

- Продукт очень широкий и может быть тяжёлым для части аудитории
- Это решение сильнее читается как “GTO-платформа”, чем как “понятный узкий тренажёр”

#### Инсайт для Firestorm

- Здесь у `Firestorm` есть шанс выигрывать у тех, кому не нужен весь тяжёлый комбайн.
- Но если мы будем слишком размазаны в позиционировании, пользователь скорее выберет более известную платформу.

## Сильные стороны конкурента

- Огромная библиотека решений
- Browser-first
- Бесплатный вход
- Широкое покрытие дисциплин
- Практика + анализ + viewer
- Сильный бренд и образовательный слой
- Очень подробная тарифная лестница

## Слабые стороны конкурента

- Высокая сложность
- Потенциальный перегруз для пользователя, которому нужен только префлоп
- Не лучший кандидат для тех, кто хочет очень узкий и понятный сценарий

## Что можно взять себе

- Free-entry как верх воронки
- Модульную лестницу value
- Связку viewer + trainer + analysis
- Сильную ясность по discipline-based planning

## Что не стоит повторять бездумно

- Избыточную платформенность без сильного узкого core
- Переусложнение первого касания ради полной системы

- Если пользователь хочет “всё и сразу”, `GTO Wizard` выглядит очень сильным выбором.

- Наше окно — не пытаться быть большим комбайном, а дать лучший продукт под более узкую реальную задачу.
