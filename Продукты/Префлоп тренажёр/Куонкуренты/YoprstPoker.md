## Краткая выжимка

- `ЁпрстПокер` прямо позиционирует себя как `Префлоп тренажёр. Тренировка префлопа NL Holdem 6 max`.
- Это не веб-платформа в стиле `FreeBetRange`, а отдельная программа под `Windows`.
- Продукт продаётся как лицензия на `1`, `3`, `6`, `12` месяцев.
- Есть `Trial`-версия, доступная после регистрации и входа в аккаунт.
- В продукте есть не только тренажёр, но и редактор чартов, перенос диапазонов из `FlopZilla` и функция `vs 3bet (Exploit)`.

## Стоимость

### Подтверждённые цены

- `1 месяц` — `700 ₽`
- `3 месяца` — `1300 ₽` вместо `1500 ₽`
- `6 месяцев` — `1900 ₽` вместо `3000 ₽`
- `12 месяцев` — `3000 ₽` вместо `3200 ₽`

### Дополнительные платные услуги

- `Внесение ваших чартов в программу` — `5000 ₽`
- `Консультация по работе программы онлайн` — `2000 ₽`
- `Ваш ник в программе` — `1000 ₽` вместо `2000 ₽`

### Выводы по стоимости

- Это очень дешёвый продукт по сравнению с большинством уже найденных конкурентов.
- Модель заточена под доступный вход и upsell через услуги.
- Продукт выглядит как “доступный рабочий тренажёр”, а не как премиальный SaaS.

#### Инсайт для Firestorm

- Если `Firestorm` будет стоить сильно дороже, без очень ясной дополнительной ценности мы будем проигрывать по perceived value.
- В этой нише низкая цена сама по себе уже часть позиционирования.

### Подтверждённые возможности

- Тренировка префлопа `NL Holdem 6 max`
- Пробная и полная версии продукта
- Редактор чартов
- Функция `vs 3bet (Exploit)`
- Перенос диапазонов из `FlopZilla`
- Пользовательские чарты
- Демо-чарты в поставке программы

### Что подтверждено по структуре продукта

- Есть отдельная видеоинструкция для тренажёра
- Есть отдельная видеоинструкция для редактора чартов
- Есть отдельная инструкция по `vs 3bet (Exploit)`
- Есть отдельная инструкция по переносу диапазонов из `FlopZilla`

### Что особенно важно

- У конкурента есть реальный акцент на практический exploit-сценарий, а не только на заучивание диапазонов.
- Отдельная платная услуга по внесению пользовательских чартов показывает, что продукт поддерживает кастомизацию, но не всё автоматизировано внутри UX.

#### Инсайт для Firestorm

- Это прямой конкурент по core use case.
- Если у нас будет более простой, современный и автоматизированный способ работы с пользовательскими чартами, это может быть реальным преимуществом.

## Доступность и UX-доступ

### Техническая доступность

- Продукт поставляется как программа под `Windows 7`, `8.1`, `10`
- Trial и полная версия скачиваются из личного кабинета
- Для доступа к trial нужно зарегистрироваться и войти в аккаунт

### Продуктовая доступность

- Есть `Trial`-версия
- Есть простая лицензируемая модель по сроку
- У продукта есть прямой self-hosted магазин без реселлера

### Ограничения

- Это не браузерный продукт
- Для начала использования требуется регистрация
- Для скачивания нужна авторизация
- Для полной версии сначала нужна оплата, затем ссылка выдаётся в личном кабинете

#### Инсайт для Firestorm

- Браузерный формат может быть нашим сильным преимуществом против `ЁпрстПокер`.
- С другой стороны, desktop-формат может восприниматься частью аудитории как “более серьёзный софт”, особенно в русскоязычном сегменте.

## Оплата

### Подтверждённые способы оплаты

- `Юмани`
- `МИР`
- `Boosty`
- через `Boosty`: `VISA`, `Mastercard`, `PayPal`
- есть отдельный путь `Реквизиты`

### Где происходит оплата

- Основная продажа идёт в собственном магазине `yoprstpoker.ru`
- На сайте есть корзина, регистрация, личный кабинет и self-hosted checkout
- Альтернативный путь оплаты предусмотрен через запрос реквизитов

### Что это значит для Firestorm

- Это хороший пример смешанной локальной модели:
- прямой checkout на своём сайте
- локальные методы (`Юмани`, `МИР`)
- дополнительный канал через `Boosty`
- запасной ручной путь через реквизиты

#### Инсайт для Firestorm

- Для русскоязычного рынка у `ЁпрстПокер` платёжная модель очень прагматичная.
- Если у нас не будет как минимум сопоставимой локальной гибкости, мы рискуем проиграть по конверсии ещё до сравнения продукта.

## Сильные стороны конкурента

- Чёткое и узкое позиционирование
- Низкая цена
- Собственный магазин без зависимости от реселлера
- Локальные способы оплаты
- Trial-версия
- Редактор чартов и импорт из `FlopZilla`
- Дополнительные услуги вокруг продукта

## Слабые стороны конкурента

- Не браузерный продукт
- UX и архитектура ощущаются более “старой школой”
- Для trial и скачивания требуется регистрация и вход
- Работа с пользовательскими чартами частично вынесена в отдельную услугу
- Видимая коммуникация продукта проще и беднее, чем у более современных конкурентов

## Что можно взять себе

- Узкое и ясное позиционирование
- Локальные способы оплаты
- Дополнительные сервисные upsell-услуги
- Простую и понятную ценовую сетку по срокам

## Что не стоит повторять бездумно

- Не стоит делать продукт зависимым от скачивания и desktop-установки, если наше преимущество в быстром веб-доступе.
- Не стоит выносить базовую кастомизацию в ручную услугу, если это можно решить продуктом.
- Не стоит делать onboarding слишком завязанным на личный кабинет до первого ощутимого value moment.

- Низкая цена
- Прямой магазин
- Понятные локальные способы оплаты
- Дополнительные ручные услуги

- Это desktop-программа, а не браузерный продукт.
