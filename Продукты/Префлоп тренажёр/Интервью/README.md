# **Intervyu po produktu**

- Папка хранит расшифровки и выжимки интервью по продукту `Префлоп тренажёр`.
- Формат имени файла интервью: `YYYY-MM-DD-Intervyu-<istochnik-ili-nik>.md`.
- Новые записи делаем только в `.md` и в формате транслита.
- Каждое интервью фиксируем в реестре: `Reestr-intervyu.md`.

## **Что фиксируем в каждом интервью**

- Дата и источник (Telegram/чат/личка).
- Контекст респондента:
`пользовался нашим` / `нашим + конкурентами` / `только конкурентами`.
- JTBD сценарий (когда/хочу/чтобы).
- Граф работ (ключевые шаги и где ломается путь).
- Инсайты и цитаты.
- Конкуренты, которые упомянуты.
- Доработки, которые советует респондент.
- Приоритет и ожидаемый эффект доработки.
