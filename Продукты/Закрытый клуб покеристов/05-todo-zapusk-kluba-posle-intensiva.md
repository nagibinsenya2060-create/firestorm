# Туду запуска PokerHUB Club после интенсива

Дата: 2026-07-02  
Статус: рабочий чеклист для Саши и команды  
Контекст: путь клиента от желания купить клуб после интенсива до первого мероприятия внутри клуба

## 0. Целевой результат

Человек после интенсива понимает, зачем ему клуб, выбирает тариф, оплачивает подписку на 30 дней, получает доступ, открывает закреп `Начни отсюда`, понимает первый шаг и приходит на первое мероприятие.

Главная логика: клуб продает не чат, а понятный следующий шаг после интенсива: план, среду, курсы, демо-продукты, живые активности и поддержку.

## 1. Решить состав тарифов Standard и Plus

### Зачем

Нужно не утверждать сам факт тарифов, а четко решить, что человек получает в каждом тарифе. Если этого не сделать, спикеры, кураторы и поддержка будут продавать разное, а участник после оплаты может не понять, за что заплатил.

### Что уже зафиксировано

Срок доступа: 30 дней.

Рабочие цены из продуктовой концепции:

- `Standard` - $19/мес.
- `Plus` - $49/мес.

Рабочая логика из текущих документов:

- `Standard` - базовый клуб: курсы, маршрут, канал, общий чат, топики по направлениям, демо-продукты, еженедельный live, записи, задания, общий Q&A.
- `Plus` - все из `Standard` плюс больше внимания: приоритет вопросов, проверка 1 задания в неделю по шаблону, участие в разборе по очереди, отдельная зона для активных участников, отдельные часы для вопросов 1-2 раза в месяц, бонус на индивидуальный разбор.

### Что нужно решить

- [ ] Проверить, что команда согласна оставить цену `Standard` $19/мес.
- [ ] Проверить, что команда согласна оставить цену `Plus` $49/мес.
- [ ] Решить, будет ли `Plus` доступен сразу на старте или его откроем позже.
- [ ] Решить конкретный лимит мест в `Plus`, потому что тариф продает внимание команды.
- [ ] Решить, что именно входит в `Standard`.
- [ ] Решить, что именно добавляется в `Plus`.
- [ ] Решить, какие пункты нельзя обещать в тарифах до готовности продукта.
- [ ] Решить, какие пункты пишем как `будет добавлено позже`, а какие не пишем вообще.

### Рабочий состав Standard

- [ ] Цена: $19/мес.
- [ ] Доступ к курсам PokerHUB по направлениям Spin, MTT, Cash и выбору дисциплины.
- [ ] Стартовый маршрут на 30 дней: что открыть, что сделать, где задать вопрос, какой следующий шаг выбрать.
- [ ] Главный канал клуба: расписание, анонсы, записи, задания, итоги и важные объявления.
- [ ] Общий чат клуба.
- [ ] Топики по направлениям: старт новичка, Spin, MTT, Cash, банкролл, румы и софт, вопросы тренеру, разборы, отчеты и задания.
- [ ] Демо-доступ к MTT-сеткам.
- [ ] Демо-доступ к тренажеру.
- [ ] Базовые чарты и стартовые материалы.
- [ ] Демо AI-бота для анализа рук, если он готов и протестирован.
- [ ] LOQER / Locker только после договоренности с Женей и подтверждения условий.
- [ ] Один общий еженедельный live: ответы на вопросы, разбор типовых ошибок или практический разбор.
- [ ] Записи live-встреч.
- [ ] Задания и отчеты.
- [ ] Общий Q&A.
- [ ] Учет прогресса через чеклист или форму.

### Рабочий состав Plus

- [ ] Цена: $49/мес.
- [ ] Лимит мест обязателен.
- [ ] Все из `Standard`.
- [ ] Приоритет вопросов к тренеру или куратору.
- [ ] Проверка 1 задания в неделю по шаблону.
- [ ] Участие в разборе участника по очереди.
- [ ] Отдельная ветка или топик для активных участников.
- [ ] Отдельные часы для вопросов 1-2 раза в месяц.
- [ ] Скидка, бонус или кредит на индивидуальный разбор, если такой апсейл запущен.
- [ ] Рекомендация следующего плана по итогам месяца.

### Что не обещаем

- [ ] Гарантированный доход.
- [ ] Гарантированное попадание в Firestorm.
- [ ] Личного тренера каждому участнику.
- [ ] Индивидуальный разбор базы всем участникам.
- [ ] Персональный план развития в базовом тарифе.
- [ ] Быстрый заработок без практики и дистанции.

### Критерий готовности

У команды есть одна финальная таблица `Standard / Plus / не обещаем`, и любой куратор может за 30 секунд объяснить разницу тарифов.

## 2. Подготовить демо-продукты, которые усиливают клуб

### Зачем

Клуб будет слабым, если продавать только общение и записи. Демо-продукты дают человеку ощущение, что после оплаты он получил конкретные инструменты, а не просто доступ к чату.

### Что нужно сделать

- [ ] По MTT-сеткам решить, какой именно демо-доступ даем: какие ABI, какие румы, какие ограничения.
- [ ] По тренажеру решить, какие тренировки доступны в демо.
- [ ] По чартам решить, какие чарты открываем в клубе.
- [ ] По AI-боту решить, готов ли он к старту клуба.
- [ ] Если AI-бот не готов, убрать его из основного обещания и оставить как будущий бонус.
- [ ] Саша связывается с Женей по LOQER / Locker.
- [ ] Договориться с Женей, можно ли давать LOQER / Locker как демо, бонус или партнерский продукт.
- [ ] Получить условия по LOQER / Locker: ссылка, доступ, ограничения, реферальная механика, формат для участников клуба.
- [ ] Для каждого демо-продукта написать простым языком: зачем он участнику.
- [ ] Для каждого демо-продукта написать инструкцию: как получить доступ.
- [ ] Для каждого демо-продукта назначить ответственного за проблемы с доступом.

### Критерий готовности

После оплаты участник видит конкретные ссылки, доступы и инструкции. Нет пункта, который обещан в продаже, но не может быть выдан.
