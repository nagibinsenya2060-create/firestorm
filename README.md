# Firestorm

## Что это за проект

`Firestorm` — рабочий проект в покерной индустрии.

Проект занимается:
- обучением покеру;
- тренировками игроков в покер;
- развитием профессиональных игроков в покер;
- монетизацией через комиссию с выигрыша игроков.

## Как использовать этот контекст

Когда в дальнейшей переписке вы говорите про `Firestorm`, базовый контекст нужно читать так:
- это не один продукт, а набор связанных продуктов;
- все материалы внутри этой папки относятся к рабочему проекту `Firestorm`;
- продуктовые, исследовательские и аналитические заметки нужно складывать в соответствующие подпапки внутри `products`.

Фиксация материалов по конкурентам должна вестись с разделением на:
